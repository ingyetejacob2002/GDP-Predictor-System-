Why a single train/test split isn't enough

The problem

With only {{ pred_vs_actual|length }} countries, one fixed 70/30 split means the result depends heavily on which rows happen to land in the test set.

Run the split a different way and the "best" model could easily change — the estimate is noisy, not trustworthy.

The fix: Leave-One-Out CV

Train on {{ pred_vs_actual|length - 1 }} countries, test on the 1 left out — repeat {{ pred_vs_actual|length }} times so every country is tested exactly once.

Average the results for a stable, low-variance performance estimate — the right approach for a dataset this size.
