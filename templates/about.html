The dataset

{{ dataset_stats.n_countries }} African countries, a single reference year ({{ dataset_stats.year }}), {{ dataset_stats.n_features }} predictor features: GDP per capita, an education index, and urban population share.

This is illustrative, single-year data built for a bootcamp exercise — realistic in shape and correlation structure, but not drawn from live labor-market records. Treat every result on this site as a demonstration of method, not a real economic finding.

Key takeaways

  • GDP per capita and education are the dominant predictors of youth unemployment in this data — urbanization showed no reliable independent relationship.
  • Simpler, regularized models ({{ final_model.name }}) matched — and in several cases beat — more complex ensembles on this small dataset.
  • Rigorous validation (Leave-One-Out Cross-Validation) mattered more than model complexity for a dataset of this size.

Next steps

  • Validate against real, multi-year data (World Bank / ILOSTAT).
  • Add features: internet penetration, informal-sector share, access to finance.
  • Revisit ensemble methods (Random Forest, Gradient Boosting) once more data reduces overfitting risk.
